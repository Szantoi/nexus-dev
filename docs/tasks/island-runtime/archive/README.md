# Archív — lezárt szigetüzemi taskok

Ide csak bizonyítékkal lezárt, `done` állapotú `TASK-ISL-*` fájl kerülhet.

1. A task végén szerepel a teljes `## Implementáció (dátum)` dokumentáció.
2. A saját készítőjétől független reviewer minden elfogadási feltételt ellenőrzött.
3. A task, az `EPICS.yaml`, a `state.md`, a `todo.md` és a `MEMORY.md` állapota
   egyezik.
4. A program README hivatkozását az `archive/` útvonalra kell átírni.
5. Nyitott kritikus vagy magas eltéréssel task nem archiválható.
